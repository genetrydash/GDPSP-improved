## GDPSP improved

Geometry Dash PSP by Yerson Games but i am improving it

To test the game ISO download the zip file "GDPSPfixed.zip" from the source code or click [HERE](https://github.com/genetrydash/GDPSP-improved/raw/refs/heads/main/GDPSPfixed.zip)

If there are any issues or bugs please report it in the issues tab
## What has been improved so far:
- Improved Physics and closer to the real game

- Increased FPS to 60 (and had to redo everything)

- The game is now faster to sync more with the music (but not finished)

- Some menu improvements

- Collision was so bad (Improved it by A LOT)

- Corner Collisions

- Ship glitching and no-clipping

- Levels are more optimized and accurate to the real game

- Updated Metatiles

- Practice Mode (beta, only works when cube and colors are messed up)

- Better Particles

- Color Improvements in main menu

- Player lerping/easing (smoother)
